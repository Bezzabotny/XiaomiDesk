# Подключение по Wi-Fi

Кабель и точка доступа телефона не нужны. Ноутбук остаётся на домашнем роутере; Xiaomi подключается к той же сети. Программа не переключает сеть ноутбука.

1. На Xiaomi включите режим разработчика: Настройки → О телефоне → несколько нажатий по версии ОС. Названия пунктов зависят от HyperOS.
2. Откройте Настройки → Расширенные настройки → Для разработчиков → Беспроводная отладка. Включите её и подтвердите разрешение для своей сети.
3. В XiaomiDesk выберите Инструменты → Подключение.
4. На телефоне откройте «Сопряжение с помощью кода». Перенесите IP:порт из этого окна и шестизначный код в шаг сопряжения приложения. Нажмите «Сопрячь устройства».
5. Закройте окно с кодом на Xiaomi. На ОСНОВНОМ экране «Беспроводная отладка» возьмите адрес подключения IP:порт. Его порт обычно отличается от порта сопряжения.
6. Введите адрес подключения и нажмите «Подключить и запомнить».
7. Оставьте галочку автоматического подключения, если телефон должен находиться при запуске приложения. Порт может меняться: приложение проверяет сохранённую аппаратную личность устройства и пробует обнаружить актуальный адрес.
8. Установите/откройте помощник из приложения и подтвердите соединение на Xiaomi. Для галереи разрешите фото и видео, для уведомлений — доступ к уведомлениям.

При следующем запуске оба устройства должны быть в доступной локальной сети, а беспроводная отладка — включена. Если автоматический поиск не сработал, обновите адрес с основного экрана отладки и подключитесь вручную.

## Частые проблемы

- Используйте адрес домашней Wi-Fi-сети Xiaomi, а не адрес VPN-интерфейса. В гостевой сети устройства могут быть изолированы друг от друга.
- При `protocol fault: couldn't read status message` заново откройте окно сопряжения на Xiaomi, проверьте адрес, новый код и порт. После сопряжения для подключения берётся другой адрес с основного экрана отладки.
- При смене сети/перезапуске отладка может выключиться. Проверьте переключатель на телефоне.
- Для USB подтвердите RSA-ключ ноутбука на Xiaomi. Установка помощника может требовать отдельного разрешения «Установка через USB».
- Управление в HyperOS может зависеть от «Отладка по USB (Настройки безопасности)». Основной режим XiaomiDesk использует физическую мышь/клавиатуру; обычные команды ввода могут быть запрещены даже при работающем изображении.

Не открывайте порт Android-отладки в интернет. Для отмены доверия удалите сопряжённый ноутбук в настройках беспроводной отладки телефона.
