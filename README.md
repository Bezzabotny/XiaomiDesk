# XiaomiDesk

[Скачать Windows 11 x64](https://github.com/Bezzabotny/XiaomiDesk/releases/tag/v0.4.1-beta.1) · [Проверки сборки](https://github.com/Bezzabotny/XiaomiDesk/actions/workflows/ci.yml)

Телефон Xiaomi рядом с Windows: галерея, файлы, экран и уведомления в одном приложении. Локальное подключение по Wi-Fi или USB, без аккаунта и облачного сервиса.

**0.4.1 beta — ранняя версия для Windows 11 x64.** Основная проверка проведена на Xiaomi с Android 16. Работа на других моделях и версиях HyperOS требует проверки. Это независимый проект, не приложение Xiaomi или Microsoft.

Версия Windows-приложения —0.4.1; включённый помощник Android —0.4. Он совместим с этой версией, его повторная установка при обновлении с0.4 не требуется.

## Начать

1. Скачайте архив Windows из раздела **Releases** и полностью распакуйте его в постоянную папку.
2. Запустите `XiaomiDesk.exe`. При обновлении сначала выберите **Выход** в меню значка старой версии возле часов.
3. Откройте **Инструменты → Подключение** и выполните настройку [Wi-Fi](docs/WIFI.md) или USB. Для Wi-Fi оба устройства должны быть доступны в одной локальной сети; переключать ноутбук на точку доступа телефона не нужно.
4. Сохраните телефон для автоматического подключения. Эту возможность можно отключить галочкой.
5. Установите помощник кнопкой приложения, подтвердите подключение на телефоне и выдайте нужные разрешения.

Windows-приложение не подписано сертификатом издателя. Отладка Android требуется для связи; помощник устанавливается на телефон отдельно из включённого APK.

## Возможности

| Раздел | Что доступно |
|---|---|
| Галерея | Миниатюры фото и обложки видео, предпросмотр, выбор и скачивание оригиналов |
| Файлы | Передача в обе стороны, перетаскивание из Проводника, прогресс, отмена и история |
| Экран | Просмотр, режим физической мыши/клавиатуры, скриншоты PNG |
| Запись | Экспериментальная запись экрана в MKV без звука |
| Ссылки и текст | Передача по кнопке; открытие HTTP(S) ссылок после явного действия |
| Уведомления | Просмотр после отдельного разрешения Android; без ответов |
| Обзор | Батарея, зарядка, температура и память по кнопке обновления |
| Фоновая работа | Значок возле часов; автозапуск Windows только по желанию |

Камера, подготовка звонка/SMS и настройки модема находятся в **Инструментах**. Сотовый звук остаётся на телефоне. Камера доступна для просмотра, виртуальной веб-камеры нет.

Галерея показывает страницы по60 элементов от новых к старым. Фильтр альбома и типа действует на текущую страницу. Видео открываются обложкой и могут быть скачаны для воспроизведения в Windows. Для оригиналов HEIC/HEIF могут понадобиться кодеки Windows.

## Проверено и ограничения

На реальном Xiaomi по Wi-Fi проверены экспорт60 элементов с60 декодируемыми обложками, скриншот PNG, сведения о телефоне и короткая запись через scrcpy. Полный запуск записи из встроенного окна в контролируемом тестовом окружении пока не подтверждён: дочерний ADB завершался с0xC0000142. Фактическую работу мыши и набора текста также нужно проверить на конкретном телефоне. [Диагностика](docs/TROUBLESHOOTING.md).

Нет подключения через интернет между разными сетями, ответов на уведомления и синхронизации всей галереи в фоне.

## Данные

Настройки и история хранятся в `%LOCALAPPDATA%\XiaomiDesk`; ключ подключения защищён Windows DPAPI для текущего пользователя. История содержит имена и пути последних100 передач. Уведомления хранятся только в памяти текущего сеанса. Миниатюры удаляются при уходе из галереи/смене устройства; после аварийного завершения временный кэш может остаться в `%TEMP%`.

Помощник запрашивает доступ к фото/видео для галереи и отдельно доступ к уведомлениям. Можно разрешить только выбранные фото. Отладка Android даёт ноутбуку широкий доступ: сопрягайте только свой компьютер. Для отключения отзовите сопряжение в настройках разработчика и доступы помощника в Android.
