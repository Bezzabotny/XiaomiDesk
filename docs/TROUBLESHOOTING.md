# Если что-то не работает

- **Телефон не найден:** откройте Инструменты → Подключение; проверьте общую Wi-Fi-сеть, беспроводную отладку и разрешение на экране Android. Адрес сопряжения и адрес подключения могут иметь разные порты.
- **INSTALL_FAILED_USER_RESTRICTED:** проверьте разрешение установки через USB в настройках разработчика Xiaomi и подтвердите установку на телефоне. Приложение показывает исходную ошибку Android.
- **Нет фото:** обновите помощник из приложения, разрешите доступ к фото/видео на Xiaomi и обновите галерею. При частичном доступе видны только разрешённые элементы.
- **Не двигается мышь / не печатает:** оставьте физический режим мыши и клавиатуры, щёлкните в изображение телефона. Левый Alt освобождает мышь. Для раскладки используйте кнопку «Раскладка». Совместимость зависит от HyperOS.
- **0xC0000142 / 3221225794:** Windows не смогла инициализировать дочерний ADB. Полностью распакуйте архив, закройте приложение через значок возле часов и запустите снова. Если ошибка сохраняется, приложите журнал потока к issue. В тестовой среде проблема воспроизводилась только во встроенном запуске, тогда как прямой запуск scrcpy работал; универсальное исправление пока не подтверждено.
- **Запись:** нажмите «Остановить» перед открытием MKV. Запись без звука; при принудительном закрытии Windows файл может остаться незавершённым.

В сообщении об ошибке укажите версию приложения, Windows/Android/HyperOS, Wi-Fi или USB, шаги и текст ошибки. Перед публикацией удалите из журналов адреса, номера телефонов и личные данные. Не прикладывайте настройки подключения или ключи.
