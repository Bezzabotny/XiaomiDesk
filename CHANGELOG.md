# Changelog

## 0.4.1-beta.1

- Подготовлен переносимый репозиторий, автоматические проверки и сборка для GitHub.
- Готовое приложение отделено от исходников и временных файлов; добавлены SHA-256 суммы.
- Ключ подписи APK вынесен из сборки; release требует явного ключа и пароля из окружения.
- Уточнены сообщения подключения и ошибки запуска ADB в Windows.
- Удалены устаревший обзор и инструкции, привязанные к конкретному устройству.
- Сохранены галерея, передача файлов, экран, скриншоты, ссылки и сведения о телефоне из0.4.

Запись из встроенного окна остаётся экспериментальной. Известные ограничения описаны в README.

Для первого релиза0.4.1 переиспользован проверенный подписанный помощник0.4 без изменений Android-кода. Проверка SHA-256 защищает импорт и упаковку от случайной подмены артефакта.
